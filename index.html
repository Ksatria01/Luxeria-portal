FAQ

Pertanyaan yang sering ditanyakan

Apakah jadibot ini gratis?[+]

Ya, mengubah nomormu jadi bot lewat pairing code ini gratis, tanpa biaya daftar atau sewa bulanan.

Apakah nomor saya aman dipakai jadi bot?[+]

Aman, kamu tetap bisa pakai WhatsApp seperti biasa di HP kamu. Bot cuma jadi "perangkat tertaut" tambahan, sama seperti WhatsApp Web.

Kenapa bot saya tidak merespon?[+]

Cek dulu status koneksinya di halaman "Bot Aktif". Kalau statusnya menunggu/putus, coba daftar ulang buat dapat kode pairing baru.

Saya nemu bug atau ada saran, ke mana kirimnya?[+]

Kirim lewat menu "Kirim Tiket" (perlu login dulu), atau chat langsung admin lewat gelembung chat di pojok kanan bawah.

LANGKAH PAIRING

Registrasi Bot

Masukkan nomor WhatsApp yang mau dijadikan bot.

luxeria // pairing-system
> LUXERIA PAIRING SYSTEM
> menunggu nomor WhatsApp...
+62
  1. Kirim nomor — format 62xxxxxxxxxx, tanpa tanda + atau spasi.
  2. Ambil kode — kode pairing 8 digit akan muncul di terminal.
  3. Tautkan — buka WhatsApp > Perangkat Tertaut > Tautkan dengan nomor telepon, masukkan kodenya.
